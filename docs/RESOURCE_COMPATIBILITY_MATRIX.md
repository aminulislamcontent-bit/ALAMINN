## Layer coverage

- **Core/orchestrator:** build independently; Ruflo/Dify/Billion Context are studies or optional services, not the core.
- **RE Lab:** Ghidra + REA + Android skills; ipftrace2 only in privileged disposable VMs; AnyPS5/WiFi cracker excluded.
- **Software Factory:** OpenCode adapter; Pocock/Android/Claude skills; CLI-Anything for harnesses; CodeRabbit optional.
- **QA:** internal Vitest/Playwright/security gates first; TestSprite/CodeRabbit optional external opinions.
- **Memory:** independent provenance store; no supplied memory repo is currently verified.
- **Creative Studio:** Presenton/HyperFrames/MoneyPrinter/Voicebox/Text-to-CAD candidates; Kdenlive/OBS/Riverside external; composite-license entries gated.
- **Governance:** existing RBAC/approval/audit foundations extended; no catalog resource replaces human approval.
